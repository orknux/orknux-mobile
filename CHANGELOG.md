# Changelog

What changed in each release, one line per change.

Written for the person deciding whether to upgrade: the change and the one thing
worth knowing about it. Not a list of commits, which git already keeps.

## 0.1.0

### ✨ Added
- Chat with a workspace's agents, with streamed answers that pick up again after a dropped connection.
- Tool and thinking lines, and plan and question cards you can answer from the phone.
- Agent, mode and effort pickers; new chats start in Auto, where agents run tools without stopping to ask, within what they have been granted.
- Attachments: send pictures and files, and open what the agent attaches in the phone's own apps.
- An eye beside your latest message once the agent has read it, and "Queued" for a message sent while it is working.
- Chats and the chat list pick up activity from other clients within a few seconds while on screen.
- Recent chats reopen instantly, at the place you were reading; the last twenty are kept encrypted on the phone and deleted on sign-out.
- Voice mode, dictation and read-aloud, using the workspace's models or the phone's own, with a thinking sound you can configure in Options.
