# Changelog

What changed in each release, one line per change.

Written for the person deciding whether to upgrade: the change and the one thing
worth knowing about it. Not a list of commits, which git already keeps.

## 0.1.0

### ✨ Added
- Chat with a workspace's agents: streamed answers that survive a dropped connection, tool and thinking lines, plan and question cards, attachments, and agent, mode and effort pickers.
- Voice mode, dictation and read-aloud, using the workspace's models or the phone's own.
- Options for choosing server or on-device speech in each direction, and for the thinking sound.
